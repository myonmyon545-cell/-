# 全作業ログの保存・提出

各役割は自分のイベントだけ追記保存し、他役割の記録を上書きしない。event_id/日時/ROLE/計画版/入力ID・版・SHA/コマンド/結果/終了コード/検証状態/出力ID・版・SHA/変更理由を記録。失敗と未検証を成功から分離。
GitHubへ安全な指示/イベント/診断/ハッシュを保存。原本・候補・未検証実データ等は既存非公開保存先へ保存。10が取得可能な全実データを別添介護保険解析_全作業ログ.zipに集約し収録台帳とSHA/CRCを検証する。
入力原本、各候補、作業/中間/試験/失敗/未検証データを同じハッシュで一度ずつ収録し、別名や版対応は全て残す。認証情報と非公開内部思考は含めない。元の各チャット公開会話を取得できた分だけ逐語収録し、未取得分はmissing_manifestへ。要約を全文保存と表示しない。
評価前T12で候補対応のログを作り、最終T08で20/30/00の評価・修正・提出記録を追加。同一候補でもログZIP版は更新し、00提出台帳に最終ログSHAを記録。最終ZIPの自己ハッシュを自身の内容へ書こうとしない。
簡易確認文はreferences/簡易確認.mdを起点に実績へ更新し別ファイルと先頭要点へ掲載。20はQ14で全収録台帳/原文と要約/未収録/検証状態/候補対応を独立確認。


## 過去会話の収録とタイムライン

logs/timeline/timeline.htmlで本文展開/検索/種類とチャットの絞込み、TIMELINE.mdでGitHub上の時系列一覧を閲覧。timeline.json/CSVとsources/には取得した原文・要約・報告全版を保存。manifest.jsonのSHAで対応付ける。送信日時が不明な会話は会話順。取得日時やコミット日時を送信日時にしない。

10はT12/T08でこのフォルダと生成コードtools/build_timeline.pyを全ログZIPへ収録する。sources/の新役割報告/会話記録を追加した固定入力から再構築し、coverage.jsonと簡易確認文の収録件数/未収録を更新。00/20/30は自役割の取得可能な公開会話や記録を10へ渡す。40は閲覧のみ。元会話全文が未取得なら要約を原文扱いしない。

再構築：python tools/build_timeline.py --source-dir logs/timeline --out <別の出力フォルダ> 。収録したsources/から入力を自動組立し、タイムライン101件・区分・出所・順序を再現する。生成時刻の差は許容。再構築後にrecords/coverage/base_commitの一致を確認して現行表示を更新。新規記録は元の役割/日時/原文または要約とともにsources/へ追加し、固定コミットを更新する。API接続や認証を生成コードへ埋め込まない。
